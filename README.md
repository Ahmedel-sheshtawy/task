# الحلم حقيقة — الإصدار 2.0 (Clean Foundation)

إعادة بناء مستقلة للمنصة. تم الاحتفاظ بتجربة التطبيق الحالية كمرحلة انتقالية، وفصل ملفات الواجهة، وإعادة ضبط المصادقة والحفظ السحابي. لا يرتبط هذا الإصدار بقاعدة D1 القديمة: أنشئ قاعدة جديدة ثم ضع معرّفها في `wrangler.jsonc`.

## ما هو موجود في هذه النسخة

- تسجيل حساب بالبريد والاسم وكلمة مرور من 8 إلى 128 حرفًا.
- تسجيل الدخول والخروج واستعادة الجلسة عبر Cookie آمنة.
- نفس خوارزمية بيانات الاعتماد المستخدمة في منصة التعليم: PBKDF2-SHA256، و100,000 iteration، وsalt عشوائي مستقل بطول 16 بايت.
- تخزين hash الجلسة فقط في D1، وليس رمز الجلسة الخام.
- إنشاء المستخدم والحالة الأولية والجلسة داخل `D1 batch` واحدة.
- حفظ بيانات كل مستخدم في سجل مستقل داخل `user_state`، مع حفظ تلقائي ومؤشر حالة الحفظ.
- عزل النسخة المحلية المؤقتة حسب معرّف المستخدم لمنع اختلاط بيانات حسابين على الجهاز نفسه.
- استيراد البيانات المحلية القديمة لا يحدث تلقائيًا؛ يظهر تأكيد صريح قبل ربطها بالحساب.
- فحص `/api/health` لقاعدة البيانات ومخطط الجداول.
- فحص Origin لطلبات الكتابة، وحماية غرف الدراسة من الوصول دون جلسة دخول.
- فصل الواجهة إلى `public/index.html` و`public/styles.css` و`public/app.js`.

## إنشاء قاعدة البيانات الجديدة

من مجلد المشروع وبعد تثبيت Node.js 22: 

```bash
npm install
npx wrangler login
npx wrangler d1 create el-helm-haqeqa-v2-prod
```

سيعرض Wrangler قيمة `database_id`. افتح `wrangler.jsonc` واستبدل النص:

```json
"database_id": "00000000-0000-0000-0000-000000000000"
```

بالمعرّف الحقيقي الذي أعاده الأمر. لا تستخدم معرّف قاعدة المشروع القديم.

ثم نفّذ:

```bash
npm run cf-typegen
npm run typecheck
npm run test:auth
npx wrangler d1 migrations apply el-helm-haqeqa-v2-prod --remote
npm run deploy
```

## ربط GitHub Actions

أضف في GitHub Repository → Settings → Secrets and variables → Actions:

- `CLOUDFLARE_ACCOUNT_ID`
- `CLOUDFLARE_API_TOKEN` — توكن Cloudflare بصلاحية Workers Scripts: Edit وD1: Edit.

بعد وضع `database_id` الجديد في `wrangler.jsonc`، أي Push إلى فرع `main` سيشغّل فحص TypeScript، ويطبق migrations، ثم ينشر Worker.

## التحقق بعد النشر

افتح:

```text
https://YOUR-DOMAIN/api/health
```

المتوقع:

```json
{
  "app": "الحلم حقيقة",
  "status": "ok",
  "database": "connected",
  "schema": "ready",
  "authentication": "enabled",
  "realtime": "ready"
}
```

اختبار قبول التسجيل: أنشئ حسابًا ببريد جديد، تأكد من دخولك مباشرة، حدّث الصفحة، تحقق من بقاء الجلسة، أنشئ مهمة وعادة وملاحظة، انتظر مؤشر «تم الحفظ»، سجّل الخروج ثم الدخول، وتأكد من عودة البيانات. اختبر أيضًا حسابًا ثانيًا على نفس المتصفح للتأكد من عدم ظهور بيانات الحساب الأول.

## أوامر التطوير المحلي

```bash
npm install
npm run cf-typegen
npx wrangler d1 migrations apply el-helm-haqeqa-v2-prod --local
npm run dev
```

## حدود هذه المرحلة

هذه نسخة أساس قابلة للنشر بعد إنشاء D1 وإدخال المعرّف. لم يتم النشر إلى حساب Cloudflare من هذه الجلسة. لم يكتمل بعد: استعادة كلمة المرور بالبريد، التحقق من البريد، صلاحيات دعوات غرف الدراسة، مشاركة المشروعات، وتحويل كل أجزاء الواجهة إلى مكونات مستقلة. البيانات التشغيلية للتطبيق ما زالت تحفظ كوثيقة JSON لكل مستخدم؛ سنقسمها إلى جداول مستقلة في مراحل لاحقة بعد تثبيت أساس الحسابات والحفظ.
